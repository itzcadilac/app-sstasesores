# Capturas de pantalla — Guía

Requisitos para Play Store:
- Mínimo 5 capturas, recomendado 6–8.
- Resolución: 1080×1920 (portrait) o superior.
- Formato: PNG sin compresión excesiva.

Pantallas sugeridas (Android):
1. Login — selección de tipo (empresa/personal/instructor).
2. Consulta de capacitaciones — listado con estados.
3. Detalle de capacitación — certificado disponible.
4. Solicitud de capacitación — formulario (presencial/virtual/in-house).
5. Perfil — datos del usuario.
6. Módulo instructor — cursos pendientes.

Cómo tomarlas (emulador):
- Abre Android Studio > AVD Manager > inicia un dispositivo.
- Ejecuta la app (debug/release) y navega a cada vista.
- Usa el botón de cámara del emulador o `Device File Explorer`.

Cómo tomarlas (dispositivo):
- Conecta por USB y habilita depuración.
- Instala APK o ejecuta desde Android Studio.
- Captura con combinación de botones del dispositivo.

Ubicación
- Guarda en este directorio con nombres descriptivos, por ejemplo:
  - `01-login.png`
  - `02-listado-capacitaciones.png`
  - `03-detalle-certificado.png`
  - `04-solicitud.png`
  - `05-perfil.png`
  - `06-instructor-pendientes.png`
